# Embedded lab samples

These files are compiled into the application. No source checkout or external sample folder is needed at runtime. Optional file pickers accept user artwork.

- `fonts/IBMPlexSans-Regular.ttf`: IBM Plex, SIL Open Font License; see [license](../../licenses/fonts/IBM-Plex.txt).
- `fonts/InterVariable.ttf`: Inter, SIL Open Font License; see [license](../../licenses/fonts/Inter.txt).
- `fonts/NotoSansArabic.ttf` and `fonts/NotoSansHebrew.ttf`: Noto Sans, SIL Open Font License; see [license](../../licenses/fonts/NotoSans.txt).
- `shader/blue_noise.bin`: unmodified xgpui shader fixture, Apache-2.0; see [NOTICE](../../NOTICE).
- `svg/AJ_Digital_Camera.svg`: AJ Ashton, public domain.
- `svg/rg1024_green_grapes.svg` and `svg/rg1024_metal_effect.svg`: rg1024, public domain / CC0-1.0.
- `svg/dragon.svg`: Ebaychatter0, CC-BY-SA-3.0, unmodified. [Source and attribution](https://commons.wikimedia.org/wiki/File:Dragon_clip_art.svg), [license](https://creativecommons.org/licenses/by-sa/3.0/).

The [SVG manifest](../../src/svg_lab/corpus.json) retains source URLs, attribution, license links and SHA-256 hashes. The corpus runs these four documents at four zoom levels (16 cases). Artwork with unclear or noncommercial redistribution terms is excluded.
