# Published Compact ICC fixtures

Unmodified sRGB-v4, DisplayP3-v4 and AdobeCompat-v4 profiles from
https://github.com/saucecontrol/Compact-ICC-Profiles at commit
`bdd84663061bc4ae95ca70decff54f581e27f702`. Upstream releases these profiles
under CC0; its full license is included. `manifest.json` records original URLs,
byte counts and SHA-256 hashes. These are the same bytes tested by xgpui's
published-profile precision corpus. AdobeCompat is independently authored and
its encoded curve is used exactly; it is not substituted with named Adobe RGB.
